# AI 提示詞十則：情境、推理、誠實與風險檢查

#ai #prompt-engineering #thinking #risk-review #workflow

## 這是什麼

這份筆記整理老闆提供的 10 張提示詞卡片，已從簡體中文轉成符合台灣正體中文語法的版本，並補成我之後可直接查用的「提示詞選擇表」。

重點不是背十句咒語，而是依當下任務選擇正確規則：要背景、要推理、要誠實、要批判、要收斂、要格式、要假設審計、要壓縮上下文，或要上線前預演失敗。

## 使用原則

- 如果老闆給的是模糊任務，先用 **情境簡報**。
- 如果老闆要決策品質，加入 **推理要求**、**誠實約束**、**假設審計**。
- 如果老闆要我挑錯或審計，使用 **魔鬼代言人** 或 **前期驗屍**。
- 如果對話變長，使用 **壓縮循環**。
- 如果老闆要短答案，使用 **格式命令**。
- 如果任務容易發散，使用 **範圍鎖定**。

## 固定觸發語：請幫我組提示詞

以後如果老闆需要我「挑出一組規則並套入情境來建立提示詞」，可以直接說下面任一種：

- `幫我組提示詞`
- `用提示詞十則幫我包一下`
- `幫我挑規則組 prompt`
- `這個需求幫我做成 AI prompt`
- `幫我用提示詞規則整理成可丟給 AI 的版本`

我收到後要做的事：

1. 先判斷任務類型與風險。
2. 從十則裡挑 1–4 個最適合的規則。
3. 說明我選了哪些規則，以及為什麼。
4. 產生一版可直接複製給任意 AI 系統使用的提示詞。
5. 如果資訊不足，列出需要補的欄位，但不要讓老闆重打廢話。

輸出格式固定為：

```txt
套用規則：
- [規則名稱]：原因

可直接使用的提示詞：
...

可選補充欄位：
- ...
```

## 十個提示詞總覽

| # | 名稱 | 用途 | 何時使用 |
|---|---|---|---|
| 1 | 情境簡報 | 讓 AI 先拿到地圖 | 任務背景不足、問題複雜時 |
| 2 | 推理要求 | 要求顯示思考架構、假設與不確定性 | 做方案、決策、分析時 |
| 3 | 誠實約束 | 要求直接指出硬傷 | 老闆可能需要聽逆耳真話時 |
| 4 | 角色設定 | 用具體經驗角色拉高推理品質 | 需要專家視角時 |
| 5 | 魔鬼代言人 | 強制反方審查 | 驗證計畫、策略、產品想法時 |
| 6 | 範圍鎖定 | 防止超出問題亂補 | 高風險、資訊不足、需要精準時 |
| 7 | 格式命令 | 控制輸出長度與結構 | 老闆只要短答案或固定格式時 |
| 8 | 假設審計 | 揭露答案底層前提 | 複雜答案後、決策前 |
| 9 | 壓縮循環 | 清掉上下文債務 | 長對話每 5–6 輪 |
| 10 | 前期驗屍 | 預演失敗原因 | 上線、發布、重大決策前 |

## 1. 情境簡報

### 圖中文字正體中文翻譯

永遠不要直接提問。

先鋪陳情境：

> 我的背景是：[角色、公司、問題]。  
> 已嘗試：[X、Y]。  
> 卡住的地方是：[Z]。  
> 請幫我釐清思路。

內部測試顯示，這個改變能提升 41% 的輸出品質。

AI 需要地圖，才能導航。

### 適合的提示詞

```txt
我的背景是：[角色 / 公司 / 任務情境]。
我目前遇到的問題是：[問題]。
我已經嘗試過：[X、Y]。
目前卡住的是：[Z]。
請先幫我釐清問題結構，再提出下一步。
```

### 我之後應該怎麼用

當老闆只丟一句方向、需求還不完整時，我應主動補成情境簡報格式再開始分析。

## 2. 推理要求

### 圖中文字正體中文翻譯

不要只問答案，要要求可檢驗的分析過程。

> 給出方案前，請逐步展示你的推理。  
> 指出不確定之處。  
> 標記所有假設。

這會要求模型輸出可檢驗的分析架構、假設與不確定性。

你得到的不只是答案，還有可以檢驗的思考過程。

### 適合的提示詞

```txt
在給出方案前，請先說明你的分析步驟。
請明確標記：
1. 你做了哪些假設
2. 哪些地方不確定
3. 哪些結論需要驗證
最後再給出建議。
```

### 我之後應該怎麼用

用於策略、技術設計、投資研究、風險判斷。注意：不要求暴露內部隱藏推理，而是要求可檢驗的分析摘要、假設與不確定性。

![提示詞 2：推理要求](notes/ai/ai-prompt-patterns/images/prompt-02.jpg)

## 3. 誠實約束

### 圖中文字正體中文翻譯

AI 系統通常會傾向配合與幫忙。

有時這代表它會說你想聽的話。

覆蓋這個傾向：

> 即使聽起來不舒服，也要誠實。  
> 如果我的計畫有致命缺陷，請直接說。  
> 不要軟化。  
> 我寧願現在聽硬話，也不要之後失敗。

這會讓模型更願意優先指出風險與缺陷。

### 適合的提示詞

```txt
請用誠實優先的方式回覆。
如果我的想法、計畫或假設有致命缺陷，請直接指出，不要為了好聽而軟化。
我寧願現在聽到難聽但準確的提醒，也不要之後踩坑。
```

### 我之後應該怎麼用

當老闆問「這樣可不可行」、「這方案有沒有問題」、「幫我看一下」時，應主動啟用這條，不要只附和。

![提示詞 3：誠實約束](notes/ai/ai-prompt-patterns/images/prompt-03.jpg)

## 4. 角色設定

### 圖中文字正體中文翻譯

「充當專家」是最弱的提示詞。

改用這個：

> 你是有 [具體經驗] 的 [特定角色]，見過 [具體失敗模式]。  
> 請用 [特定框架] 思考。  
> 直言不諱，跳過一般建議。

身份越具體，推理越具體。

模糊角色 = 模糊輸出。每次都是。

### 適合的提示詞

```txt
請用這個角色視角回答：
你是有 [具體年資 / 產業 / 場景經驗] 的 [特定角色]，
見過 [常見失敗模式]，
請用 [框架 / 方法論] 分析。
請跳過常識型建議，直接講高價值判斷。
```

### 我之後應該怎麼用

不要只說「以專家角度」。要指定：資深 PM、SRE、資安審查者、量化交易研究員、Laravel 架構師、AI workflow designer 等。

![提示詞 4：角色設定](notes/ai/ai-prompt-patterns/images/prompt-04.jpg)

## 5. 魔鬼代言人

### 圖中文字正體中文翻譯

AI 被訓練得很溫順。

打破這個模式：

> 我要分享一個計畫。  
> 你的工作是摧毀它。  
> 找出所有錯誤假設、被忽略的風險，以及可能失敗的原因。  
> 不要手軟。

這是 Anthropic 團隊內部檢驗想法的方式。

挑戰你的模型，比同意你的模型有 10 倍價值。

### 適合的提示詞

```txt
我要分享一個計畫。
你的任務不是同意我，而是用魔鬼代言人的角度摧毀它。
請找出：
1. 錯誤假設
2. 被忽略的風險
3. 最可能失敗的原因
4. 我現在最該修正的地方
不要手軟。
```

### 我之後應該怎麼用

用於產品想法、交易策略、技術架構、創業計畫、重大決策前的反方檢查。

![提示詞 5：魔鬼代言人](notes/ai/ai-prompt-patterns/images/prompt-05.jpg)

## 6. 範圍鎖定

### 圖中文字正體中文翻譯

AI 系統常會回答你的問題，再加上幾個衍生方向。

早期就鎖定範圍：

> 嚴格限於 [X 背景]。  
> 超出範圍就告訴我，而不是推測。  
> 我要的是缺口，而不是自信但錯誤的答案。

這會從源頭殺死幻覺。

AI 會停止用看似可信的虛構內容填補空白。

### 適合的提示詞

```txt
請嚴格限制在這個範圍內回答：[範圍 / 背景 / 資料來源]。
如果資訊不足或超出範圍，請直接標記「不知道 / 需要補資料」，不要推測。
我要的是缺口與限制，不是自信但錯誤的答案。
```

### 我之後應該怎麼用

用於法律、財務、技術除錯、文件摘要、來源有限的分析。若資料不足，要說不足。

![提示詞 6：範圍鎖定](notes/ai/ai-prompt-patterns/images/prompt-06.jpg)

## 7. 格式命令

### 圖中文字正體中文翻譯

AI 系統預設常會寫得比較全面。

但你可能需要簡潔。

提前設定格式：

> 結構如下：  
> 1）一句話總結。  
> 2）三個重點。  
> 3）一個下一步建議。  
> 除非我追問，其他都不要。

多數 AI 系統都很吃明確格式指令。

要有意識地使用這種精準性。

### 適合的提示詞

```txt
請嚴格用以下格式回答：
1. 一句話總結
2. 三個重點
3. 一個下一步建議
除非我追問，其他都不要補充。
```

### 我之後應該怎麼用

老闆用 Telegram 時常需要短答案；此時應優先用格式命令，避免長篇大論。

![提示詞 7：格式命令](notes/ai/ai-prompt-patterns/images/prompt-07.jpg)

## 8. 假設審計

### 圖中文字正體中文翻譯

任何複雜答案之後，都要跑這個：

> 你做了哪些我應該驗證的假設？  
> 如果這些假設是錯的，答案會怎麼改變？

這是最少被使用的提示詞。

它會揭露每個回答底下隱藏的基礎。

大多數計畫都是在基礎處崩塌。

### 適合的提示詞

```txt
請審計你剛剛回答中的假設：
1. 你做了哪些我應該驗證的假設？
2. 如果這些假設錯了，結論會怎麼改變？
3. 哪個假設最脆弱、最需要先確認？
```

### 我之後應該怎麼用

在產出方案、交易計畫、架構設計、研究結論後，我應主動補一段「假設審計」。

![提示詞 8：假設審計](notes/ai/ai-prompt-patterns/images/prompt-08.jpg)

## 9. 壓縮循環

### 圖中文字正體中文翻譯

在長對話中，AI 系統會累積上下文債務。

每 5–6 次互動：

> 總結目前進展。  
> 我們正在解決什麼問題？  
> 已經決定了什麼？  
> 還沒解決、最重要的一件事是什麼？

讓對話鎖定在真正重要的事情上。

避免 AI 系統自信地解決錯誤問題。

### 適合的提示詞

```txt
請做一次壓縮總結：
1. 我們正在解決什麼問題？
2. 已經完成或決定了什麼？
3. 目前最重要的未決問題是什麼？
4. 下一步應該做什麼？
```

### 我之後應該怎麼用

多輪任務、長 debug、長研究、連續改檔時，每隔一段時間主動壓縮，避免上下文債務。

![提示詞 9：壓縮循環](notes/ai/ai-prompt-patterns/images/prompt-09.jpg)

## 10. 前期驗屍

### 圖中文字正體中文翻譯

在 AI 協助你做出的東西上線前：

> 假設這件事 6 個月後失敗。  
> 請列出 3 個最可能的原因。  
> 要具體。  
> 失敗實際上會長什麼樣子？

這類 pre-mortem 常用於產品與策略決策前的風險檢查。

它能抓到其他審查流程遺漏的問題。

### 適合的提示詞

```txt
請做前期驗屍：
假設這件事 6 個月後失敗。
請列出 3 個最可能的失敗原因。
每個原因都要具體說明：
1. 失敗會長什麼樣子
2. 早期警訊是什麼
3. 現在可以怎麼降低風險
```

### 我之後應該怎麼用

用於上線前、發布前、部署前、策略執行前、重大承諾前。這比普通 review 更能抓盲點。

![提示詞 10：前期驗屍](notes/ai/ai-prompt-patterns/images/prompt-10.jpg)

## 我應該主動套用的選擇規則

| 老闆當下情境 | 我應主動啟用 |
|---|---|
| 老闆只給一句模糊方向 | 情境簡報 |
| 老闆問「你覺得怎樣」 | 誠實約束 + 假設審計 |
| 老闆給計畫要我看 | 魔鬼代言人 |
| 老闆要上線 / 部署 / 發布 | 前期驗屍 |
| 老闆要求短答 | 格式命令 |
| 對話變長、資訊很多 | 壓縮循環 |
| 資料來源有限 | 範圍鎖定 |
| 需要專業判斷 | 角色設定 |
| 技術 / 策略方案 | 推理要求 + 假設審計 |

## 組合模板

### 一般高品質分析

```txt
我的背景是：[背景]。
我遇到的問題是：[問題]。
我已經嘗試：[X、Y]，目前卡在：[Z]。

請先釐清問題結構，再給建議。
回答時請標記你的假設、不確定之處，以及我需要驗證的關鍵前提。
如果我的方向有致命缺陷，請直接說。
```

### 嚴格決策審查

```txt
請用魔鬼代言人的角度審查這個計畫。
找出錯誤假設、被忽略的風險、最可能失敗的原因。
接著做一次前期驗屍：假設 6 個月後失敗，列出 3 個具體原因、早期警訊與現在能做的降低風險措施。
```

### 短版 Telegram 回覆

```txt
請嚴格用以下格式回答：
1. 一句話總結
2. 三個重點
3. 一個下一步建議
除非我追問，其他都不要補充。
```
