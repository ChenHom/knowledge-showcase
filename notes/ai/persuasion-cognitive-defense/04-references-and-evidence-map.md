# 文獻與證據地圖：說服、信任、誤信與認知防禦

#research #bibliography #persuasion #misinformation #critical-thinking

## 這是什麼

集中記錄「矛與盾」研究的原始文獻、可以支持的論點、研究類型，以及移用到技術文章時的限制。以下並非宣稱每篇都已完成逐頁全文精讀：有些核對了出版社全文或可取得的原文，有些僅核對出版社摘要與書目資料。

## 核心結論

- **理論模型、單項實驗、統合分析、實務方法**的證據層級不同，不能混寫。
- 學術研究處理的多半是新聞、廣告、敘事或一般網站；用於 GitHub README、AI 技術文章與提示詞教學，是**需要驗證的跨場景應用**。
- 統合分析的效果量不等於一般人的成功率或改進百分比。
- 本系列的「A 雙循環」與「B 主張—證據—推論—行動」是研究整理出的工作模型，**不是原論文中已經證實的統一理論**。

## B：盾——誤信與防禦

| ID | 文獻 | 類別 | 可支持的範圍與限制 |
|---|---|---|---|
| R7 | Rogers et al. (2017), [Artful Paltering](https://doi.org/10.1037/pspi0000081) | 兩項前導研究、六項實驗 | 刻意用真實陳述造成誤導印象；「刻意」是要件，不可未經證據推定作者動機 |
| R8 | Pennycook et al. (2020), [The Implied Truth Effect](https://doi.org/10.1287/mnsc.2019.3478) | 實驗 | 只警告部分假新聞會影響未標記新聞的可信度；不能直接套用為技術文章的定量風險 |
| R9 | Aslett et al. (2024；2023 線上先發), [Online Searches to Evaluate Misinformation Can Increase Its Perceived Veracity](https://doi.org/10.1038/s41586-023-06883-y) | 五項實驗 | 低品質搜尋結果可造成查證反效果；不表示所有搜尋都有害 |
| R10 | Pfänder & Altay (2025), [Spotting False News and Doubting True News](https://doi.org/10.1038/s41562-024-02086-1) | 預先註冊統合分析 | 67 篇實驗研究、194,438 人；在其新聞資料中存在將真新聞判假的偏向，不能推廣到所有領域 |
| R11 | DeVerna et al. (2024), [Fact-checking Information from Large Language Models Can Decrease Headline Discernment](https://doi.org/10.1073/pnas.2322823121) | 預先註冊隨機實驗 | 部分 LLM 查核回應可能降低標題真偽辨識；不代表所有 AI 查核都無效 |
| R12 | Simchon et al. (2026；2025 線上先發), [A Signal Detection Theory Meta-analysis of Psychological Inoculation Against Misinformation](https://doi.org/10.1016/j.copsyc.2025.102194) | 33 項實驗的重新分析（N = 37,075） | 支持部分事前心理接種方式提升可靠／不可靠新聞的辨別能力；不是技術文章模型已獲驗證 |
| R13 | Hoes et al. (2024), [Prominent Misinformation Interventions Reduce Misperceptions but Increase Scepticism](https://doi.org/10.1038/s41562-024-01884-x) | 三國線上實驗（N = 6,127） | 部分防假資訊措施也降低對真實資訊的信任；不同國家效果可能不同 |
| R14 | Buçinca, Malaya & Gajos (2021), [To Trust or to Think: Cognitive Forcing Functions Can Reduce Overreliance on AI](https://doi.org/10.1145/3449287) | 人機互動實驗 | 主動思考介入可在其任務中減少 AI 過度依賴，但帶來認知成本；非技術文章現成實驗 |
| R15 | Caulfield, [SIFT：Stop、Investigate、Find better coverage、Trace](https://guides.umd.umich.edu/SIFT) | 資訊素養實務方法 | 提醒追原始來源、尋獨立資料；本身不是判斷真假成功率的保證 |

## 研究證據與應用主張的對應

| 本系列主張 | 文獻支持 | 仍屬本系列推論的部分 |
|---|---|---|
| 讀者可能使用來源形象而非深入論證 | R2、R4 | 哪一種 GitHub 技術文最容易觸發 |
| 信任牽涉能力、意圖與承擔風險 | R1、R5 | 一套適用技術創作者的長期信任追蹤方法 |
| 敘事可影響故事一致信念 | R3 | 經驗故事＋因果解釋一定是最佳文章結構 |
| 部分真實的敘述仍可誤導 | R7 | 某個具名作者是否有意誤導 |
| 只標部分警告可能帶來副作用 | R8、R13 | 技術文章專屬警示工具的誤判率 |
| 搜尋與 AI 查核並非永遠可靠 | R9、R11 | 哪種具體閱讀 SOP 有最高成效 |
| 事前訓練可能提高辨別能力 | R12 | 本系列六類技術文章操縱手法的訓練效果 |

## 閱讀與再驗證順序

**A 優先**：R1 → R2 → R3 → R4 → R5 → R6。由信任本質、說服條件、敘事機制，讀到商業意圖與信任修復。

**B 優先**：R7 → R10 → R8 → R9 → R11 → R12 → R13 → R14。先理解真話如何誤導與懷疑偏向，再比較警示、搜尋、AI 查核與心理接種的利弊。

不能僅因論文存在或 DOI 正確，就推論論文支持所有延伸說法。每次引用應核對研究族群、訊息類型、介入方式、結果指標與發表版本。

## 尚未解決、可繼續研究的問題

1. 當讀者相信作者在 PHP 或 AI 開發上的能力，這份信任如何轉移到資安、硬體或商業推薦？需要跨領域直接實驗。
2. 技術文章常混合真實原理與未證實成果，既有新聞真假研究在這種「部分真實」情境是否依然適用？
3. 哪一種介入時機（閱讀、分享、安裝前）能有效改善判斷，又不造成全面懷疑或警示疲勞？
4. 用主張—證據—推論—行動的程序，是否能降低錯信，同時維持對有證據內容的接受？
